# homebrew-tap

```sh
brew install abdiraimov-otabek/tap/diskreceipt
brew install abdiraimov-otabek/tap/claude-done
```

- [diskreceipt](https://github.com/abdiraimov-otabek/diskreceipt): the receipt for the developer caches on your Mac. Read-only.
- [claude-done](https://github.com/abdiraimov-otabek/claude-done): a notification and a sound when Claude Code finishes or needs you.
